   with recovery advice. Tests include scalar documents, list statuses, null/
   list stores and malformed reference metadata at table and summary levels.

   running module's resolved path. Missing/unrelated metadata yields unknown.
   Source checkouts still use the project's single version definition. A real
   copied-module CLI export and mocked owned/unowned/missing distributions pass.

   Both raw and finalized unavailable status are tested. The unreleased inline
   migration branch is deleted; inline references and old boundary identities
   are refused with regeneration advice. No historical evidence is migrated.

   raw/final unavailable status, forged text, identity conflicts and ownership.
